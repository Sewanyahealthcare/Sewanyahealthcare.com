# Sewanya / SampoornaCare Healthcare Portal - Demo

यह ZIP एक original frontend demo है जो दिए गए screenshot की visual direction से inspired है।

Included:
- index.html
- style.css
- script.js

Modules:
- Healthcare home page
- Hospital / health services
- DM (District Manager)
- BM (Block Manager)
- FO (Field Officer)
- All UP district selector
- District → Block selector
- Dashboard statistics
- Transactions table
- Withdrawal UI
- Support section
- Mobile responsive layout

IMPORTANT:
यह केवल frontend/demo है। वास्तविक login, database, KYC, wallet balance, bank/UPI verification और real withdrawal/payment के लिए secure backend + authentication + payment gateway integration आवश्यक है।
